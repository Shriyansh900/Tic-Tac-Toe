# Tic Tac Toe Game 🎮  

A minimalistic and elegant implementation of the classic Tic Tac Toe game using HTML, CSS, and JavaScript.  

## 🌟 Features  
- **Responsive Design**: Enjoy the game on any device.  
- **Interactive Gameplay**: Automatically detects winners or a draw.  
- **Lightweight**: Built with pure HTML, CSS, and JavaScript—no dependencies.  

## 🚀 How to Play  
1. Two players take turns marking the grid with `X` or `O`.  
2. The first to align three in a row—horizontally, vertically, or diagonally—wins!  
3. If the grid is filled without a winner, the game ends in a draw.  

## 📂 Project Structure  
- `index.html`: Main structure of the game.  
- `style.css`: Styles for the game layout and animations.  
- `script.js`: Handles game logic and interactivity.
